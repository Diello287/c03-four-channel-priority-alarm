# Application

## Purpose
The Four-Channel Priority Alarm Selector combines four 2-bit alarm sources into one output describing the highest-priority active alarm.

## Intended Use
- Educational demonstration of digital priority-selection logic.
- Practice with combinational Verilog RTL.
- Demonstration of exhaustive simulation and a Tiny Tapeout-style physical design flow.

## Limitations
This project is an educational design. It is not claimed to be certified or ready for use in a safety-critical alarm system.
